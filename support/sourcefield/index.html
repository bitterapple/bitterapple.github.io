SourceField

Public preview — Version 1.0.0.

Free 2D Source Placement Plug-in

SourceField places a mono or stereo source on a 2D field around the listening point. Move the source on an XY matrix, rotate the source direction, and rotate the listener direction from the center point to shape where the sound appears to come from.

SourceField is being released early because the basic idea is already useful: a sound source, its facing direction, and the listener's facing direction can all be adjusted on one 2D surface. More controls and sound-model revisions are planned.

What it does

  • Places a mono or stereo source around a listener-centered XY field.
  • Changes left/right position, front/back distance, and source direction in one visual control.
  • Lets the listener direction rotate too, so the same source position can feel different as the listening point turns.
  • Combines the kind of spatial softening explored in PanBlur with the front/back placement idea of Distance.
  • Works as a practical mix tool for making a source feel placed, aimed, or offset without setting up a full surround or game-audio scene.

Concept

Source Position

Move the sound on an XY field instead of thinking only in pan or width.

Source Direction

Rotate where the source is facing, changing the feeling of projection and off-axis placement.

Listener Direction

Keep the listener at the center, then turn the listening direction to reshape the perspective.

Current state

This first public build is a preview. The core interaction is in place, but the sound, parameter set, and supported formats may change as SourceField grows. Treat it as an early spatial tool rather than a finished final model.

Requirements

  • Windows plug-in host with VST3 support.
  • Package: SourceField-windows-vst3.zip
  • macOS formats are planned for a future release.

Install

  1. Download SourceField-windows-vst3.zip.
  2. Unzip the package and place the VST3 file in your Windows VST3 folder.
  3. Launch your DAW and rescan plug-ins if SourceField does not appear.
