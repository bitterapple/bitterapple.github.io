BandMatrix

Released — Version 1.6.0.

6-Band SideChain Compressor / Expander Router

BandMatrix is a macOS dynamics plug-in (AAX / AU / VST3) built for multi-band sidechain compression with flexible key routing. Each band can be driven by the internal signal, the external sidechain input, or even an arbitrary other band — so you can create targeted, musical ducking and inter-band control. Version 1.6.0 includes an update intended to address a reported Windows issue, although this has not yet been fully confirmed.

What it does

  • Split the signal into multiple bands and apply independent compression per band.
  • Per band, choose a key source: Internal, External sidechain, Mix, or Other band.
  • Create precise ducking (e.g., kick → bass low band) and inter-band control (e.g., harsh band → tame presence) without affecting the entire spectrum.
  • Version 1.6.0 includes an update intended to resolve a reported Windows issue, although this has not yet been fully confirmed.
  • Tone Shaper mode adds a more flexible way to shape spectral balance inside the band matrix workflow.
  • The window is now resizable for easier editing on different screen sizes.

Typical use cases

Kick / Bass

Duck only the bass low band from the kick, keeping mids and highs stable and punchy.

Vocals / Music

Make space for vocals by gently ducking specific instrument bands using internal or external keys.

Sound design

Create inter-band dynamics (one band driving another) for movement, emphasis, and controlled aggression.

Requirements

  • Apple Silicon Mac.
  • A plug-in host that supports AAX (Pro Tools), AU, or VST3.
  • Installer: BandMatrix_1.6.0.pkg

Install

  1. Download the latest BandMatrix_1.6.0.pkg from this page.
  2. Run the installer (it installs AAX / AU / VST3 to the standard macOS plug-in locations).
  3. Launch your host (e.g., Pro Tools) and rescan plug-ins if needed.
