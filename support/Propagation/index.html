New Release

Propagation

Live

Released — Version 1.0.0.

Propagation is an algorithmic reverb shaped by impulse-response analysis. It studies curated IRs, extracts their spatial character, and turns that information into a parameter set you can actually play with, rather than locking you to a single frozen response. Version 1.0.0 is the first public release.

The current concept also includes user IR loading, so your own captured spaces can be analyzed in the same way and used as flexible starting points. I still have more ideas for it, so the feature set may continue to evolve quite a bit after this first release.

What makes it different

IR as a starting point

Instead of treating an IR as a fixed destination, Propagation extracts usable traits from multiple spaces and lets you steer them with an algorithmic engine.

Your own spaces too

User IR import is part of the design, so personal captures can go through the same analysis pipeline and become editable, morphable reverb sources.

Control language beyond usual reverb

The current build explores controls such as Space Size, Density, IR Morph, Clarity, Transient, Width, M/S Bias, and shaping moves like Push Back, Bring Forward, Open Wide, and Tighten.

Built for exploration

The goal is a reverb that can move through families of spaces quickly, without losing the recognizable character extracted from the source IR material.
