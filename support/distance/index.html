Distance

Released — Version 1.0.0.

Distance Perception Shaping Plug-in

Distance is a macOS audio plug-in (AAX / AU / VST3) designed to change the perceived distance of a sound source in a more natural way than simple reverb or EQ. When you want something to feel a few meters farther away, traditional tools often miss the mark. Distance aims to make that kind of depth shift feel more believable, practical, and musical.

Initial release is coming soon. The plug-in is intended to keep improving over time as better distance-shaping algorithms are developed.

What it does

  • Change the perceived distance of a source without relying on reverb alone.
  • Help sounds feel farther away or closer in a way that is more convincing than simple tonal darkening.
  • Aim for subtle, useful depth control that can sit naturally inside a real mix.
  • Focus on being a practical utility plug-in rather than a flashy special effect.
  • The algorithm is expected to keep evolving after release as new ideas and improvements are implemented.

Typical use cases

Vocals

Move a vocal slightly back in the mix without relying on an obvious reverb tail.

Dialogue / FX

Help dialogue, foley, or effects feel a few meters farther away in a more believable way.

Mix depth

Create clearer front-to-back placement when EQ and reverb alone do not quite get there.

Requirements

  • Apple Silicon Mac.
  • A plug-in host that supports AAX (Pro Tools), AU, or VST3.
  • Installer: Distance_1.0.0.pkg

Note: The initial release will include AAX / AU / VST3 builds for Apple Silicon.

Install

  1. Download the latest Distance_1.0.0.pkg from this page when the release becomes available.
  2. Run the installer to place AAX / AU / VST3 into the standard macOS plug-in locations.
  3. Launch your host application and rescan plug-ins if needed.
