Propagation

Released — Version 1.0.1.

IR-Driven Algorithmic Reverb

Propagation is an algorithmic reverb shaped by impulse-response analysis. It studies curated IRs, extracts their spatial character, and turns that information into a parameter set you can actually play with, rather than locking you to a single frozen response. Version 1.0.1 is the current release.

Propagation 1.0.1 is now publicly available. This update fixes a bug, and I still have more ideas for it, so the controls, layout, and overall direction may continue to change quite a bit in future updates.

What it does

  • Build reverb behavior from curated IR analysis instead of freezing a single response in place.
  • Use user IR loading as a flexible starting point for further shaping and experimentation.
  • Explore spaces with controls such as Space Size, Density, IR Morph, Clarity, Transient, Width, and M/S Bias.
  • Treat the source IR as a starting point, not a fixed destination, so you can push it toward new spatial characters.
  • This first release is public now, but the feature set may continue to evolve substantially in future updates.

Typical use cases

Musical spaces

Move quickly between room characters without being locked to a single static IR.

Sound design

Push a captured space toward something less literal and more playable inside a mix or effect chain.

IR experimentation

Use your own impulse responses as flexible source material rather than fixed end states.

Requirements

  • macOS 11 or later.
  • A plug-in host that supports AAX (Pro Tools), AU, or VST3.
  • Installer: Propagation_1.0.1.pkg

Note: The installer includes AAX / AU / VST3 builds for macOS 11 or later. Windows VST3 is provided separately as a ZIP download.

Install

  1. Download the latest Propagation_1.0.1.pkg from this page.
  2. Run the installer (it installs AAX / AU / VST3 to the standard macOS plug-in locations).
  3. Launch your host and rescan plug-ins if needed.
