# Multilingual site

Jekyll remains the site generator. The existing English product pages and download redirect front matter are authoritative, and products.json is the app update manifest.

- _data/products.yml: product summaries, latest summaries and dates.
- _data/i18n.json: site text and translation snapshots for product/release summaries. Changed English text falls back to English instead of showing stale translations.
- _data/i18n_support.json: translated privacy policy, product route/download/App Store mapping and download screen labels.
- Localized product pages currently contain a translated overview and recent update, links to the original complete documentation and the same download routes. Detailed manuals and historical release notes have not yet been translated; this is explicitly marked on every localized product page.
- Existing TakeFlow and its workflow guide have a separate localization system. RecScript invitation is a functional deep-link endpoint and is not changed.
- When changing product routes or publishing new download routes, update the mapping and page wrappers, then validate locally.
- Run ruby _scripts/validate_i18n.rb, bundle exec jekyll build, ruby _scripts/validate_i18n.rb --built. No GitHub Actions are required to validate locally.
