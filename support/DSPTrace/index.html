DSPTrace

Preview — In development.

AU / VST Parameter Response Analysis

DSPTrace is an in-development analysis plug-in that loads AU and VST plug-ins, automatically moves their parameters, and measures how those control changes affect the audio. The aim is to make processor behavior easier to observe, compare, and document in a repeatable way.

Status: Preview page • Public build: Not available yet

This page is an early look at the current direction. The feature set, layout, supported formats, and analysis workflow may still change before the first public release.

What it aims to do

  • Load AU and VST plug-ins inside DSPTrace for controlled analysis.
  • Automatically vary parameters and measure how those changes alter the resulting audio.
  • Help reveal what a plug-in’s controls are really doing, not just what their labels imply.
  • Make it easier to compare processor behavior across versions or across different plug-ins.

Why I’m building it

Plug-in research

Check how an EQ, compressor, saturator, or other processor actually responds as parameters move.

Behavior comparison

Compare different plug-ins or compare versions of the same plug-in using the same measurement flow.

Parameter tracing

Turn vague control labels into something more concrete by observing their sonic effect directly.
