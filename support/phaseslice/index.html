PhaseSlice

Released — Version 1.0.0.

5-band split-delay and phase-shaping plug-in

PhaseSlice is a macOS plug-in (AAX / AU / VST3) that goes one step past a band-pass filter: instead of just isolating a frequency range, it lets you delay only that band by a few milliseconds up to longer texture-shaping values, then blend it back with per-band mix, trim, polarity, and phase control.

What it does

  • Split the signal into 5 crossover-based bands that sum back together cleanly.
  • Delay each band independently with Delay, Mix, and Trim controls.
  • Shape interference and depth with Polarity and All-pass phase amount per band.
  • Keep the result practical with output trim, limiter, auto gain compensation, and delay smoothing options.

Main controls

Band split

  • Xover1-4 (Hz) for the 5-band crossover.
  • Default working points: 120 / 450 / 2k / 6k.
  • The crossover is designed so the bands recombine cleanly at the dry baseline.

Per-band delay

  • Delay[i]: 0-1000 ms for each band.
  • Mix[i]: 0-100% dry/wet blend per band.
  • Trim[i]: -12 to +12 dB for band-by-band level correction.

Phase tools

  • Polarity[i]: on/off per band.
  • Phase mode: Off / All-pass.
  • Phase amount[i]: 0-100% per band.
  • Solo / Mute per band.

Safety and stereo

  • Output trim: -24 to +24 dB.
  • Limiter: on/off.
  • Auto gain comp: on/off.
  • Delay smoothing: Off / Light / High.
  • Stereo link: 0-100%.

Interface overview

Top section

FFT display, crossover markers, and a delay profile view so the band timing shape is visible at a glance.

Bottom section

Focused editing for the selected band: delay, mix, trim, phase, polarity, solo, and mute.
