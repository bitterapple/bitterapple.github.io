PhaseSlice

In development — first public release in preparation.

5-band split-delay and phase-shaping plug-in

PhaseSlice is a macOS plug-in concept that goes one step past a band-pass filter: instead of just isolating a frequency range, it lets you delay only that band by a few milliseconds up to longer texture-shaping values, then blend it back with per-band mix, trim, polarity, and phase control.

What it does

  • Split the signal into 5 crossover-based bands that sum back together cleanly.
  • Delay each band independently with Delay, Mix, and Trim controls.
  • Shape interference and depth with Polarity and an optional All-pass phase amount per band.
  • Keep the result practical with output trim, limiter, auto gain compensation, and delay smoothing options.

Initial parameter set

Band split

  • Xover1-4 (Hz) for the 5-band crossover.
  • Working draft: 120 / 450 / 2k / 6k as the default crossover points.
  • Crossover design target: a split that recombines cleanly for the dry baseline.

Per-band delay

  • Delay[i]: 0-1000 ms for each band.
  • Practical sweet spot is expected to be around 0-100 ms.
  • Mix[i]: 0-100% dry/wet blend per band to avoid turning every move into a full-strength comb filter.
  • Trim[i]: -12 to +12 dB for band-by-band level recovery.

Phase tools

  • Polarity[i]: on/off per band.
  • Phase mode: Off / All-pass.
  • Phase amount[i]: 0-100%, with the all-pass design following the band center frequency under the hood.
  • Solo / Mute per band for tuning by ear.

Safety and control

  • Output trim: -24 to +24 dB.
  • Limiter: on/off.
  • Auto gain comp: on/off.
  • Delay smoothing: Off / Light / High for delay moves.
  • Latency mode: zero-latency split first, linear phase as a possible later option.
  • Stereo link: 0-100%, with LR mode first and MS as a possible future extension.

Interface direction

Top section

FFT display, crossover markers, and a delay profile view so the band timing shape is visible at a glance.

Bottom section

Focused editing for the selected band: delay, mix, trim, phase, polarity, solo, and mute.
