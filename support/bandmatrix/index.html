BandMatrix

Released — Version 3.2.0.

Free Variable-Band Sidechain Dynamics Plug-in

BandMatrix is a free variable-band sidechain dynamics plug-in with compression, expansion, flexible matrix routing, Tone Shaper mode, and Inverse sidechain mode. Each band can listen to the internal signal, external sidechain input, or another band, so you can create targeted ducking and inter-band control without compressing the whole mix.

What it does

  • Choose the active band count, split the signal into multiple bands, and apply independent compression per band.
  • Per band, choose a key source: Internal, External sidechain, Mix, or Other band.
  • Create precise ducking (e.g., kick → bass low band) and inter-band control (e.g., harsh band → tame presence) without affecting the entire spectrum.
  • Version 3.0.0 adds variable band count support and makes the matrix routing more flexible for sidechain dynamics workflows.
  • Tone Shaper mode adds a more flexible way to shape spectral balance inside the band matrix workflow. Version 3.2.0 fixes an issue in Tone mode.
  • The window is now resizable for easier editing on different screen sizes.

Typical use cases

Kick / Bass

Duck only the bass low band from the kick, keeping mids and highs stable and punchy.

Vocals / Music

Make space for vocals by gently ducking specific instrument bands using internal or external keys.

Sound design

Create inter-band dynamics (one band driving another) for movement, emphasis, and controlled aggression.

Requirements

  • macOS 11 or later.
  • A plug-in host that supports AU or VST3.
  • Installer: BandMatrix_3.2.0.pkg

Note: The installer includes AU / VST3 builds that target macOS 11 or later.

Install

  1. Download the latest BandMatrix_3.2.0.pkg from this page.
  2. Run the installer (it installs AU / VST3 to the standard macOS plug-in locations).
  3. Launch your host and rescan plug-ins if needed.
