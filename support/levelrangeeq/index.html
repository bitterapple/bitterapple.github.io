Level Range EQ

Version 2.3.0 — Out now.

Free Level-Dependent EQ Plug-in

Level Range EQ is a free level-dependent EQ plug-in that applies different EQ curves to quiet, mid-level, and loud parts of a signal. Version 2.3.0 is a bug fix update for the previous release, while keeping the Tone Shaper and Dynamic EQ workflows available in the same plug-in.

What it does

  • Apply different EQ depending on the signal’s level.
  • Three level ranges: Low, Mid, High.
  • Each range has its own EQ curve, so you can shape whispers / normal / peaks differently.

Typical use cases

Vocals

Keep quiet phrases warm, keep normal phrases clear, and tame harsh peaks — without crushing everything into one curve.

Dialogue / VO

Different tonal balance for low-level room tone vs spoken words vs loud consonants — useful for consistent intelligibility.

Instruments

Shape sustain and transients differently (e.g., brighten attacks while keeping body smooth).

  2. Run the installer (it installs AAX / AU / VST3 to the standard macOS plug-in locations).
  3. Launch your host (e.g., Pro Tools for AAX, or any AU/VST3 host) and rescan plug-ins if needed.
